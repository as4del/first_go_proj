# LinkForge: фронтенд

Обычные HTML, CSS и JavaScript. Сборка, npm и вспомогательный сервер не нужны. Все добавленные файлы находятся в `frontend/`; существующий Go-код не изменён.

## Как подключить

Статика уже подключена в `main.go`. Запусти backend из корня проекта привычным способом и открой **http://localhost:8080/**.

### Маршрут входа

Текущий backend регистрирует `GET /login`, но обработчик `Login` читает JSON. Браузерный `fetch` не поддерживает тело GET-запроса, поэтому форма входа отправляет **POST /login**. Для работы формы самостоятельно замени одну строку в `main.go`:

```go
server.POST("/login", handler.Login)
```

Перезапусти backend после изменения. Go-файлы при обновлении фронтенда не менялись. При старом маршруте форма покажет ошибку подключения входа.

Без подключения статики или разрешения CORS на сервере отдельный HTML-файл не сможет обращаться к API с cookie. `session.Save()` сохраняет сессию, но само по себе не снимает браузерные ограничения между разными адресами/портами. Используй один и тот же hostname: не смешивай `localhost` и `127.0.0.1`.

## Возможности

- Регистрация: `POST /new_user` с `username`, `email`, `password`.
- Вход: `POST /login` с `username`, `password` (нужно изменить метод маршрута, как описано выше).
- Выход: `GET /logout`, затем проверка отсутствия сессии через `/api/me`.
- Проверка сессии при открытии и по кнопке: `GET /api/me`.
- Создание ссылки: `POST /new_url` с `short`, `original`; имя пользователя берёт backend из сессии.
- Список своих ссылок: `GET /url_for_user` с поиском по уже загруженному списку.
- Копирование адресов и открытие коротких ссылок через `GET /get/:name`.
- Показ ошибок API, пустого списка, загрузки и истёкшей сессии.

Все API-запросы используют `credentials: 'include'`. Cookie сохраняет и отправляет браузер; JavaScript не читает HttpOnly cookie. Имя пользователя не служит заменой авторизации и не сохраняется в localStorage. После регистрации фронтенд отдельно проверяет `/api/me`.

В карточке аккаунта можно переключаться между входом и регистрацией. После подтверждения `/api/me` загружаются ссылки пользователя и появляется кнопка выхода. После выхода список очищается. Ошибка входа или выхода показывается на странице.

Пароль передаётся API при регистрации или входе и очищается из формы после запроса. Его обработка и хранение остаются ответственностью существующего backend.

Шрифт Golos Text подгружается из Google Fonts; без интернета используется системный шрифт.
